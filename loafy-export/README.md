# Loafy — MVP 디자인 프로토타입

출석하면 고양이가 날렵해지고, 빠지면 식빵이 되는 출석 앱의 클릭 가능한 디자인 프로토타입.

## 파일
- `Loafy App.dc.html` — 앱 전체 프로토타입. PC에서는 프레임 없이 480px 컬럼, 모바일 웹은 꽉 찬 화면 (Tweaks `frame`으로 폰 프레임 전환).
  - 스플래시(픽셀 로고) → 로그인 → 온보딩 9단계(약관 · 기본정보 · 이름 · 목표 체형 · 출석 장소 · 털색 · 빵틀 색 · 횟수/알림 · 규칙)
  - 홈(빵틀 3D · 출석) · 빵틀 크게 보기(상태 카드) · 출석 완료 · 공유카드(이미지 저장) · 사연 보내기/내역/수정
  - 기록(캘린더 · 월 휠 선택) · 샵(발자국 쿠키 · 구매 시트 · 광고 제거권) · 마이 · 꾸미기(빵틀/고양이) · 출석 알림
- `Loafy Screens.dc.html` — 개발 전달용 보드. 같은 앱을 화면별로 띄움 + PC 뷰 + 캐릭터/아이콘 시트.
- `loafy-sprites.js` — 32×32 픽셀 고양이(체형 6 · 털색 7 · 표정 7 · 포즈 4), 12×12 픽셀 아이콘, LCD 시뮬레이터, 픽셀 로고(`loafy-logo`), 발자국 화면 전환(`loafy-paws`).
- `loafy-tama.js` — three.js 3D 빵틀 (드래그 회전, 버튼, 체인/무늬 액세서리, 화면 탭 → 크게 보기, 말풍선, 스냅샷).
- `support.js` — 디자인 컴포넌트 런타임.
- `fonts/PretendardVariable.woff2` — Pretendard.
- `assets/Loafy.svg` — 로고 원본.

## 실행
로컬 서버로 열기 (ES module / fetch 때문에 file:// 불가):
```
npx serve .
```
→ `http://localhost:3000/Loafy%20App.dc.html`

three.js는 unpkg CDN(0.160.0)에서 로드.

## 참고
- 결제(쿠키 충전 · 아이템 구매)는 테스트 동작이며 실제 결제는 일어나지 않음. 출시 시 스토어 인앱결제 연동 필요.
- 광고 배너 자리는 320×50 플레이스홀더(`data-ad-slot`).
