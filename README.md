# Loafy — MVP 디자인 프로토타입

출석하면 고양이가 날렵해지고, 빠지면 식빵이 되는 출석 앱(헬스장 출석 + 운동 기록)의 클릭 가능한 디자인 프로토타입.

## 파일
| 파일 | 내용 |
| --- | --- |
| `Loafy App.dc.html` | 앱 전체 프로토타입. 모든 화면과 흐름이 연결돼 있어요. PC에서는 프레임 없이 480px 컬럼, 모바일 웹은 꽉 찬 화면이에요. (Tweaks의 `frame`으로 폰 프레임 전환, `start`로 시작 화면 선택) |
| `Loafy Screens.dc.html` | 개발 전달용 보드. 같은 앱을 화면마다 띄워서 한눈에 보여줘요. PC 뷰와 캐릭터/아이콘 시트 포함 |
| `Loafy Assets.dc.html` | 아이콘 · 캐릭터 아카이브. 체형 6 × 털색 7, 표정, 포즈, 액세서리, 3D 빵틀(모양/무늬/배경), 12×12 픽셀 아이콘 전체, 털색 팔레트 |
| `Loafy Widgets.dc.html` | iOS 위젯 시안(홈 Small/Medium, 잠금 화면). 앱과 별도로 개발 |
| `loafy-sprites.js` | 32×32 픽셀 고양이, 12×12 픽셀 아이콘, 빵틀 화면(LCD) 시뮬레이터와 픽셀 배경, 픽셀 로고, 발자국 화면 전환 |
| `loafy-tama.js` | three.js 3D 빵틀. 360° 회전, 버튼, 무늬/체인/귀/꼬리, 화면 탭 → 크게 보기 |
| `support.js` | 디자인 컴포넌트 런타임 |
| `fonts/PretendardVariable.woff2` | Pretendard |
| `assets/Loafy.svg` | 로고 원본 |

## 실행
로컬 서버로 열어요. (file:// 로는 동작하지 않아요)
```
npx serve .
```
→ `http://localhost:3000/Loafy%20App.dc.html`

three.js는 unpkg CDN(0.160.0)에서 불러와요.

## 화면 흐름
스플래시(픽셀 로고) → 로그인(Apple · 카카오 · 네이버 · Google · 게스트) → 온보딩 → 홈 · 기록 · 샵 · 마이

- **온보딩:** 약관 동의(전문 보기) · 기본정보 · 이름 · 목표 체형 · 출석 장소(건너뛰기) · 털색 · 빵틀 색 · 출석 횟수와 알림 시간 · 성장 규칙
- **홈:** 3D 빵틀, 출석하기 → 출석 완료 모달(운동 기록 / 공유카드), 알림, 공유(이미지 저장), 빵틀 화면 탭 → 크게 보기(상태 카드)
- **운동 기록:** 운동 고르기(추천 루틴 · 검색 · 즐겨찾기 · 운동 상세 시트) → 세트/시간/강도(고양이 표정)/메모, 칼로리 자동·직접 → 완료 화면(강화된 고양이, 한 운동, 운동 부하)
- **기록:** 월 선택 휠이 있는 캘린더(출석 · 사연 · 결석), 날짜 상세, 사연 보내기와 수정
- **샵:** 빵틀(모양 · 액세서리 · 무늬 · 케이스 · 배경) / 고양이(액세서리 · 털색), 발자국 쿠키 충전, 광고 제거권
- **마이:** 이번 달 성장(칼로리 · 근력 · 지구력 · 진화 진행 막대), 퀵버튼(빵틀 꾸미기 · 고양이 변경 · 사연 내역), 알림 설정(출석 시간 / 알림 종류), 사운드

## 개발 시 참고
- **결제:** 쿠키 충전과 아이템 구매, 광고 제거권(₩9,900)은 테스트 동작이에요. 실제 앱에서는 스토어 인앱결제가 필요해요.
- **광고 배너:** 320×50 자리 표시예요(`data-ad-slot`).
- **소리:** 코드로 합성한 시안용 효과음이에요. 실제 앱에서는 음원 파일을 넣어주세요.
- **운동 정보:** 운동 28종의 타입, 장비, 부위는 예시 값이에요. 운동 자세 일러스트는 자리만 있어요(픽셀 아이콘).
- **칼로리와 성장 수치:** 임시 계산식이에요. 소모 = 시간 × 강도 계수, 근력 = 세트 수, 지구력 = 유산소 5분당 1이에요.
- **알림과 위젯:** iOS 푸시 권한 팝업, 알림 종류, 위젯은 디자인 시안이에요. 위젯은 WidgetKit과 App Group, 출석 버튼은 App Intents(iOS 17+)로 구현해야 해요.
- **약관 문안:** 예시 문안이라 출시 전 법률 검토가 필요해요.
- 상태는 브라우저 메모리에만 있어요. 새로고침하면 초기화돼요.
